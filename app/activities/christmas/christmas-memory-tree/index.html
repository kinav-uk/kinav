A Christmas memory tree

Everyone adds a Christmas memory to a paper tree, and by the end of the month it's full of stories.

For care homes, day centres and families with older relatives. Takes about 30 to 45 minutes.

You'll need

  • A big paper tree shape on the wall, or a small real tree
  • Paper baubles or stars, cut out ready
  • Pens and something to stick them up with

How to run it

  1. Put the tree up somewhere everyone passes.
  2. Ask one question a day, such as "What was your best ever Christmas present?"
  3. Write each answer on a bauble with the person's first name, or help them write it.
  4. Read a few out each day, and let people add more whenever they like.

Make it easier

  • Offer to write for anyone who would rather talk than write.
  • A photo of a bauble with a memory makes a lovely thing to send to family.
